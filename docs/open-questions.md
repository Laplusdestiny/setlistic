## 決定済み（2026-10-11）

- **ログイン方法**：Supabase無料プランに含まれる方式だけにする。Google OAuthを基本とし、必要ならGitHubなど無料のソーシャルログインを追加。メール＋パスワード、マジックリンク、SMS、Appleでサインインは採用しない（メール送信に外部SMTP、Appleは有料登録が必要なため）。モック01のメール欄は実装しない

- **タググループと別名（#1）**：採用。`tag_groups` / `tag_aliases` を使う
- **習熟度の持ち方（#2）**：タグに一本化。`songs` に習熟度の列は持たない。既定タグ「歌える度」グループに 十八番・歌える・練習中・歌いたい
- **招待の方法（#3）**：許可リスト `allowed_emails` にはメールの SHA-256 のみを保存し、Supabase の Before User Created フック（`public.hook_before_user_created`）で未許可アカウントの作成自体を拒否する。MVP はオーナーのみ。メールアドレスそのものはアプリのテーブルに持たない
- **`/add?url=` の仕様（#4）**：URL欄に入った状態で開く。自動取得・自動保存はしない。未ログインならログイン後に戻る
- **ひらがな・カタカナの揺れ吸収（#6）**：MVPでは対応しない（全角半角・大文字小文字・半角カナは NFKC で吸収する）。読み仮名と曲名順は GitHub Issue #2 で扱う
- **Phase 5 の実装方針**：タグ・カスタム項目の並べ替えはドラッグではなく↑↓ボタン（キーボード・スクリーンリーダーで使える）。アカウント削除は、呼び出したユーザー自身の行だけを消す DB 関数 `delete_my_account`（サービスロールキーは使わない）。エクスポートは JSON（再インポート用・名前で参照）と CSV。インポートは追加のみで、既存のデータは消さない
- **タグのドラッグでの並べ替え（Issue #32、2026-10-19）**：タグ管理の「管理」で、タグの行をドラッグ（PC）・長押ししてから移動（スマホ）で並べ替えられる。別のグループまで動かすとグループも移る。↑↓ボタンはキーボード・スクリーンリーダー用に残す。グループの並べ替えとカスタム項目は↑↓ボタンのまま。タグ名で検索しているあいだは並べ替えできない。ライブラリは使わず Pointer Events で実装し、保存は既存の `reorder_tags` を使う（DB の変更なし）
- **ダークテーマ（#7）**：MVPはライトのみ。`user_settings` にテーマ列は持たない
- **チュートリアルとヘルプ（Issue #18、2026-10-18）**：
  - チュートリアルは `/welcome?step=...`（4手順。ホーム画面から起動しているときは「ホーム画面に追加」を飛ばして3手順）。完了は `user_settings.tutorial_completed_at`（アカウント単位）に持ち、null のあいだはホームを開くとチュートリアルへ送る。既存ユーザーはマイグレーションで埋めた。スキップ・あとで登録する・1曲登録できたときに記録し、設定から見返しても日時は変えない
  - 1曲登録は登録画面と同じ取得・登録処理を使い、確認画面を挟まずに登録する。Spotify / YouTube Music で Apple Music の曲と確信できないときは、取得元の表記で登録する。登録時に付けるタグは付ける
  - 色は資料のオレンジではなく既存のトークン（強調は `--color-primary` の紺、主ボタンは `--color-ink`）。等幅フォントは DM Mono を読み込まず端末の等幅フォント
  - 「タグを付ける」は曲の画面を編集状態で開く（`/songs/[id]?edit=1`）
  - ヘルプは GitHub Pages ではなくアプリ内の `/help`（ログイン不要）。節の id は `src/lib/help.ts`。対応サービスの一覧は `src/lib/songs/services.ts`（Apple Music・Spotify・YouTube Music）から作る。問い合わせ先は利用規約と同じく「招待時にお伝えした連絡先」
- **練習の優先順位（Issue #11、2026-10-20）**：`songs.practice_priority`（1=高・2=中・3=低、null=未設定）。『歌える度』タグとは連動させず、利用者が自分で外す。ホームに『練習する』チップ（優先度あり＋優先度順）。検索は高だけ・中以上・設定あり。まとめて編集は `bulk_edit_song_tags` の引数で同じトランザクションに含める

## モックアップにない画面（実装時にデザインを起こす）

- URLが読み取れない・曲が見つからないときのエラー表示

- 検索画面の AND/OR 切り替え、除外、項目条件、並び替え、保存した検索条件
