# デザインシステム

`design/mockups/` の12画面から抽出した値。実装では CSS 変数（または Tailwind の theme 拡張）として定義し、コンポーネントに直書きしない。

## コンセプト

「紙のセットリスト」。生成り色の紙に、紺のインクで曲名を書いたような見た目にする。装飾は控えめで、店の暗い照明でも読める濃いコントラストを保つ。

### ダークテーマ

設定画面に「テーマ：端末に合わせる」があるが、ダーク配色はまだ作っていない。MVPはライトのみで、トークン経由にしておけば後から足せる（open-questions参照）。

## 主なコンポーネント

- **フィルターチップ**：高さ36px、角丸999px。未選択は紙色＋枠線、選択中は `--color-ink` 背景に白文字。横スクロールで並べる
- **タグバッジ**：`#タグ名` 表記。11px、角丸6px、`--color-tag-bg` / `--color-tag-fg`
- **キー表示**：`キー -2` のように枠線付きの小さな札。値は `-7〜+7`、0は `±0`
- **曲リスト行**：曲名・アーティスト・タグ、右にキー（曲番号は振らない）
- **一覧カード**：紙色、枠線、角丸16px、上部に「SET LIST」と件数、下に点線
- **スマホのタブバー**：セトリ／検索／（中央の＋）／タグ／設定。中央ボタンは56px角で少し浮かせる
- **PCレイアウト**：左サイドバー（ロゴ、セトリ、タグ管理、設定、＋曲を登録）＋絞り込みパネル＋曲一覧＋詳細パネルの3ペイン
- **キー増減**：−／＋のボタンで−7〜+7の範囲を1ずつ変える
- **削除系**：文字だけのボタン、`--color-danger`。実行前に確認ダイアログ

## アクセシビリティ

- タップ領域は44px以上（モックで統一済み）
- アイコンだけのボタンには `aria-label`
- 検索欄は視覚的に隠した `<label>` を持つ
- ナビゲーションには `aria-label`（例：「メインメニュー」）
